Choose what the dashboard can do there

The server decides what it allows; the dashboard can only ask. Use smctl on the server, and the change shows up here within 30 seconds.

# one-click deploy (runs your script; --sudo runs it as root)
sudo smctl action add deploy -d "Pull and restart" -- /opt/deploy/deploy.sh

# Restart button for a detected service
sudo smctl service restartable nginx on

# make an app log tail-able
sudo smctl log add app /var/www/app/logs/app.log

# see everything, or diagnose problems
sudo smctl list
sudo smctl doctor
