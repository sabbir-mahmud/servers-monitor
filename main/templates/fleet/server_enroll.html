One-line install

For Debian, Ubuntu or RHEL with systemd. Run it as root. It creates a server-monitor system user, installs the agent with its own virtualenv in /opt/server-monitor-agent, writes /etc/server-monitor-agent/agent.toml (mode 640) and starts the systemd unit.

curl -fsSL {{ public_url }}/agent/files/install.sh | sudo SM_URL={{ public_url }} SM_TOKEN={{ token }} bash

Declare what this server may do

Edit /etc/server-monitor-agent/agent.toml on the server to list its services, log files and deploy scripts, then run sudo systemctl restart server-monitor-agent. The dashboard only offers, and the agent only runs, what that file allows. See the annotated example.
